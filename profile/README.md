# Tone Labs

Independent software studio building developer tools, platform infrastructure, and full-stack products.

## Open source

- **[ghx](https://github.com/tone-labs/ghx)**: the pull-request review views the GitHub CLI leaves out. Inline threads with resolution state, the review decision, and a merge-readiness gate, in the terminal, for people and coding agents. `brew install tone-labs/tap/ghx`
- **[dewey](https://github.com/tone-labs/dewey)**: database-agnostic filtering, sorting, and pagination for Go REST APIs. Zero dependencies, works with Ent, GORM, sqlc, or raw SQL.
- **[curator](https://github.com/tone-labs/curator)**: admin UI components for React, built on Refine and Mantine, that pair with dewey on the server.

## Products

- **[Handscape](https://handscape.poker)**: poker hand ranges as 3D landscapes.
- **[Strawberry](https://strawberry.garden)**: a live reference app built on dewey and curator.
